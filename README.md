# Saltbound (Fabric 1.21.1)

Souls-like механики для Minecraft: соль, святилища, выносливость, перекаты, атрибуты.

## Быстрый старт
См. файл `КАК ЗАПУСТИТЬ.txt` (build.bat собирает мод в один клик).

## Сборка вручную
Нужны JDK 21 и Gradle 8.10+. Если нет gradlew, скопируйте `gradlew`, `gradlew.bat` и папку `gradle/wrapper`
из шаблона https://github.com/FabricMC/fabric-example-mod (ветка 1.21) либо выполните `gradle wrapper`.

    ./gradlew build          # jar в build/libs/
    ./gradlew runClient      # запуск клиента для теста

Версии Fabric API / Loader в gradle.properties сверяйте с https://fabricmc.net/develop

## Игра
- Убиваете враждебных мобов: получаете соль (макс. здоровье x 4; дракон 10000, визер 5000).
- Смерть: вся соль остаётся в "пятне" на месте смерти (синие огни видны только вам). Подойдите, чтобы вернуть.
  Умрёте с солью, не вернув старую: старая пропадает.
- Святилище (ломается только киркой, минимум каменной; рукой не выпадает). Крафт: obsidian-кольцо, soul lantern, gold block; есть во вкладке Functional): ПКМ.
  Задаёт точку возрождения, лечит, возрождает убитых мобов в радиусе 48 блоков, открывает меню прокачки.
- Выносливость (зелёная шкала слева внизу): удар -8, перекат -20. На нуле бить нельзя.
- Перекат: Left Alt (меняется в настройках управления), короткая неуязвимость. Без ввода: отскок назад.
- Атрибуты: Живучесть (+1 сердце), Сила (+0.4 урона), Ловкость (+скорость атаки и регенерация выносливости),
  Выносливость (+4 макс. выносливости).

Рекомендуется `/gamerule keepInventory true`, чтобы терялась только соль.

## Баланс (константы в начале Saltbound.java, таблица соли в SaltValues.java)
- Соль за мобов зависит от типа (zombie 6-10, creeper 9-15, witch 15-25, ravager 45-65, wither ~2500, дракон ~5700).
- Смерть: любая смерть до сбора старой соли стирает её (экран смерти показывает предупреждение).
  `OLD_STAIN_LOST_EVEN_IF_EMPTY = false`: стирать только если несёшь новую соль.
- Рывок: на земле и один раз в воздухе за прыжок (`ALLOW_AIR_DASH`).
- Возрождение мобов у святилища: перезарядка 5 мин на святилище, не больше 20 за раз, не больше 25 врагов рядом,
  возрождённые дают x0.6, x0.36, x0.22... соли.

## HUD и фляга
- HUD (вариант A): слева вверху эмблема с уровнем, полоса здоровья, полоса выносливости, слот фляги; соль слева внизу.
  Ванильные сердца скрыты (mixin). Броня и голод остаются ванильными.
- Красная фляга: R. Питьё 1 сек, во время него вы медленнее; урон, удар или перекат прерывают питьё
  (заряд при этом не тратится). Лечит max(8, 40% макс. здоровья). 3 заряда, пополняются в святилище.
- Z: переключение предмета быстрого слота (пока он один, готово под будущие фляги).
- Константы фляги: FLASK_* в начале Saltbound.java.

## Серебро
- Источники: редкий дроп с мобов, гарантированно с боссов и сильных мобов (~10% их соли), монеты в сундуках структур.
- Монета (предмет): ПКМ, вся стопка переходит в серебро.
- Тратится в святилище на улучшения фляги: заряды (40/120/300) и лечение (30/90/200/400).
- Смерть: -5% серебра (константа SILVER_DEATH_LOSS_PERCENT в Saltbound.java).

## Текстуры HUD
- Исходники слоёв: assets/saltbound/textures/gui/hud/ (frame, hp_fill, hp_trail, st_fill, flask_full, flask_empty),
  нарезаны из присланного набора (масштаб x0.4). Рядом лежат .mcmeta с blur (сглаживание).
- Полоса здоровья фиксированной длины (100% = вся полоса); деления на ней нарисованы в текстуре.
- Шрифт чисел сейчас ванильный. Для шрифта с засечками нужен файл шрифта (ttf) или битмап-набор цифр.
